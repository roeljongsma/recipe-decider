# 🍴 Munchoice

Pick what to munch — your personal recipe stash and meal decider.

## What it does
- 📚 Store your recipes (title, servings, ingredients with amounts, steps)
- 📋 Bulk-paste ingredients from any source — auto-parsed into editable rows
- 🔍 Search your recipes by name or ingredient
- 🎲 "Surprise me!" randomizer when you can't decide
- 🥦 Filter by ingredients, auto-grouped by category (carbs, protein, veggies, etc.)
- 🌍 English / Dutch language toggle

## Tech
- Plain HTML / CSS / JavaScript (no framework)
- Supabase for auth + database
- Hosted on Vercel
